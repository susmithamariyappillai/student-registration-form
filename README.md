
# Student Registration Form

A simple and responsive **Student Registration Form** created using HTML, CSS, and JavaScript.

## 🚀 Live Demo

🔗  https://susmithamariyappillai.github.io/student-registration-form/

## 📂 GitHub Repository

🔗 https://github.com/susmithamariyappillai

## ✨ Features

* Student Name input
* Email input
* Password input
* Name validation
* Email validation
* Password validation
* Minimum 6 characters for password
* Submit button
* Displays saved student details after submission
* Prevents form submission when required fields are empty

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 📋 Form Fields

| Field    | Description                    |
| -------- | ------------------------------ |
| Name     | Enter student's name           |
| Email    | Enter student's email          |
| Password | Minimum 6 characters           |
| Submit   | display successfully registration |

## 💻 How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Enter the student details.
5. Click **Submit**.
6. The show successfully registration
